# Fogão Fácil

Projeto acadêmico da disciplina UX e Interface do Fogão, com o objetivo de
apresentar uma nova interface acessível para um fogão, considerando diferentes
tipos de deficiência e necessidades específicas.

## Conteúdo do projeto

- Apresentação do projetista
- Nova interface acessível do fogão (imagem própria, pasta `img/`)
- Manual de utilização do fogão

## Tecnologias utilizadas

- HTML
- CSS inline
